# `42`·`guides` 최종 확정 체크리스트

이 임시 저장소의 결정이 모두 닫히면 `42`와 `guides`의 실제 `main` 문서 세트를 만든다.

## 1. PATH

- [ ] 프로젝트 24개의 순서·이름·진입 조건이 확정됐다.
- [ ] 필수 가이드 15개와 조건부 가이드 2개의 역할이 확정됐다.
- [ ] 하드 게이트가 실제 문서·코드 의존성과 모순되지 않는다.
- [ ] P/G/L 원자성, WIP 상한과 연결 감사 횟수가 확정됐다.
- [ ] 그래프와 `PROJECTS.md`·`GUIDES.md`가 같은 사실을 말한다.

## 2. `42`

- [ ] orphan branch 8개와 독립 정본 5개의 분류가 확정됐다.
- [ ] `web-boundary-inspector`와 `portfolio-site`의 42 외부 위치가 확정됐다.
- [ ] 같은 코드가 branch와 독립 저장소 양쪽에 존재하지 않는다.
- [ ] `main` README에는 색인·정책만 남았다.
- [ ] 각 branch에 README·LICENSE·검증 진입점이 있다.

## 3. `guides`

- [ ] 17개 branch 이름이 확정됐다.
- [ ] 이전 개별 guide 저장소의 archive·삭제 정책이 확정됐다.
- [ ] 모든 가이드는 해당 orphan branch 하나만 정본으로 사용한다.
- [ ] `main` README에는 학습 지도·운영 정책만 남았다.
- [ ] 각 branch가 자신의 예제·실습·CI·LICENSE를 소유한다.

## 4. 문서와 링크

- [ ] 상대 링크만 사용하며 현재 존재하지 않는 branch 링크를 미리 만들지 않는다.
- [ ] README에서 같은 사실을 여러 번 정의하지 않는다.
- [ ] 프로젝트·가이드 상세는 각 정본 표로만 연결한다.
- [ ] 이미지의 SVG·PNG와 편집 원본 DOT·Mermaid가 함께 있다.
- [ ] `make check`가 깨진 링크, 누락 파일, 중복 공고와 생성물 drift를 거부한다.

## 5. 라이선스

- [ ] 직접 작성 코드·테스트·자동화는 MIT다.
- [ ] 직접 작성 문서·도식은 CC BY 4.0이다.
- [ ] 42 subject, 평가표, 로고와 외부 자료는 정본 라이선스에서 제외한다.
- [ ] 각 orphan branch를 단독으로 받아도 라이선스를 확인할 수 있다.
