# 확정 결정 기록

## 저장소 목적

- 이름: `engineering-path-review`
- 형태: `.git` 이력을 포함하지 않는 문서 저장소 패키지
- 수명: `42`와 `guides` 구조·문서·PATH를 검토·개선·확정하는 동안만 사용하는 임시 저장소
- 비범위: 프로젝트 코드의 새 정본, 실제 채용 지원 관리 시스템, 공고 자동 수집기

## 문서 구조

- 루트 README는 관제판만 담당한다.
- PATH, 프로젝트, 가이드, 저장소 전략, 채용 전략, 공고 snapshot, 체크리스트를 각각 한 정본 문서로 둔다.
- 프로젝트·가이드 설명은 `한 줄 역할 + 진입 조건 + 완료 결과`로 제한한다.
- 내부 링크는 상대 경로만 사용한다.
- 그래프는 Mermaid, DOT, SVG, PNG를 모두 제공한다.

## 저장소 공개

- `42/main`: 과제 색인·정책·라이선스만
- `42`의 작은 과제: orphan branch
- 독립 제품 프로젝트: 별도 정본 저장소
- `guides/main`: 가이드 색인·학습 경로·정책·라이선스만
- 모든 가이드: orphan branch, 별도 정본 없음
- 동일 코드·문서의 복수 정본은 허용하지 않는다.

## 채용 검색

- 직군: 프런트엔드, 풀스택, Node·TypeScript 백엔드, Java·Spring 백엔드, C·C++ 시스템·서버, 일반 주니어 개발
- 범위: 한국 전국·원격, 한국에서 가능한 해외 원격
- 고용: 정규직 또는 정규직전환형
- 경력: 신입, 경력 무관, 1~3년 요구까지 후보
- 출처: 기업 공식 페이지 우선, 플랫폼 보조
- 상태: 공고중과 만료를 분리하고 중복 제거
- 등급: 즉시 지원, 조건부 지원, 향후 지원
- 보존: 2026-08-03 정적 snapshot, 자동 수집·자동 갱신 없음
