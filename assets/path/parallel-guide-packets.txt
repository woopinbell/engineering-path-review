SYNCHRONIZATION SEMANTICS
A → B is a directed gate: B waits for A to be complete; A does not wait for B.
Reaching or running A is insufficient. A's chapter, exercise, verification, and P0/P1 closure must be complete.
The receiving track also keeps its own internal predecessors, so A alone is not a sufficient condition for B.
C-S01, WEB-S01, SB-S01, and SB-S02 are checkpoints, not learning blocks.
WEB-G01 through WEB-G06 require only G00 and WEB-internal predecessors; the first external wait is WEB-S01 before WEB-G07.

VISUAL LEGEND
All synchronization checkpoint nodes share one amber palette.
Hard-synchronization relations do not use one global red color; source cells retain the provider track color.
